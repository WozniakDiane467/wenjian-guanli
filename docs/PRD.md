# PRD — 电脑桌面管理（需求文档）

## 1. 产品定位

一个给自己用的桌面端文件自动整理工具。核心价值：**把「桌面 / 下载 / 文档」里散乱的文件，自动归类到规范文件夹**，省去手工收拾的麻烦，同时全程安全可控。

## 2. 核心决策（已拍板）

| 维度 | 决策 |
|---|---|
| 核心能力 | 自动整理归类 |
| 自动化程度 | 半自动：先出清单 → 用户确认 → 才执行 |
| 使用对象 | 自己用 |
| 安全兜底 | 删/移一律进回收站 + 可撤销 |
| 技术栈 | Python 3.11+ + PySide6 |
| 扫描范围 | 默认「桌面 + 下载 + 文档」，绝不碰系统目录，可自选目标 |
| 分类规则 | 按文件类型 7 大类，规则可配置 |

## 3. 功能主流程

```
[选目录] → [扫描] → [分类] → [出清单表格] → [勾选] → [确认弹窗] → [执行] → [撤销/查看日志]
```

1. **选目录**：默认桌面/下载/文档三个，也可自选任意文件夹。
2. **扫描**：递归扫描该目录下所有文件，跳过系统目录（见第 5 节）。
3. **分类**：给每个文件打上分类标签 + 建议目标路径。
4. **出清单**：表格展示 文件名 / 大小 / 分类 / 建议目标路径，前面带勾选框（默认全选）。
5. **确认**：点「执行」时弹确认提示（"确认整理 N 个文件？"）。
6. **执行**：对勾选文件执行移动或进回收站。
7. **撤销 / 日志**：可一键撤销上一步；可查看操作日志和统计。

## 4. 分类规则（7 大类）

| 分类 | 典型扩展名 |
|---|---|
| 文档 | .doc .docx .pdf .txt .md .xls .xlsx .ppt .pptx |
| 图片 | .jpg .jpeg .png .gif .bmp .svg .webp |
| 视频 | .mp4 .avi .mov .mkv .wmv .flv |
| 音频 | .mp3 .wav .flac .aac .ogg |
| 压缩包 | .zip .rar .7z .tar .gz |
| 安装包 | .exe .msi .dmg .apk |
| 其他 | 未匹配到的 |

> 规则做成「可配置」，放在 `src/core/classifier.py` 里的分类映射表，方便以后增改。

## 5. 安全红线（硬约束，不可违反）

1. **绝不永久删除**：删除动作一律走「进回收站」，不用 `os.remove` / `shutil.rmtree` 硬删。
2. **系统目录禁区**：以下目录一律跳过、绝不操作——`C:\Windows`、`C:\Program Files`、`C:\Program Files (x86)`、系统盘根目录、`AppData`、`System32` 等。
3. **半自动**：任何移动/删除前必须有用户确认，AI 不擅自执行。
4. **可撤销**：每步操作压入撤销栈，支持一键回退。
5. **重名保护**：移动时目标已存在同名文件，自动加后缀（如 `名(1).ext`），不覆盖。

## 6. 验收口径（总统筹用）

- 工具能启动、能走通「选目录→扫描→出清单→确认→执行→撤销」主流程。
- 绝不碰系统目录、绝不永久删除、重名不覆盖。
- 每个模块有测试，`pytest` 通过。
- 4 个 agent 各自的工作记录完整可读。
