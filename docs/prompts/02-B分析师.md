## 关键设计要求

- **扫描**：用 `os.walk` / `pathlib` 递归遍历；遇到 `is_safe()` 返回 False 的目录就跳过；只收**文件**，跳过文件夹本身。
- **分类 7 大类**：文档 / 图片 / 视频 / 音频 / 压缩包 / 安装包 / 其他。扩展名映射参考 PRD.md 第 4 节，`CATEGORY_RULES` 做成可配置映射表。
- **suggested_path**：建议目标 = 当前文件所在盘符下（或用户自选根目录下）按分类建子文件夹，例如 `.../图片/xxx.jpg`。具体目标根目录规则可先按「文件当前所在目录」归类到其下的分类子文件夹，或与 D 约定后写清——若拿不准，写一个合理默认并在工作记录里说明。
- **未知扩展名**归「其他」。
