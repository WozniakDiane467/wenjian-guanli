## 项目背景（一句话）

一个给自己用的桌面端文件自动整理工具（Python 3.11+ + PySide6）：把「桌面/下载/文档」里散乱的文件自动归类到规范文件夹，先出清单、用户确认后才执行，删/移一律进回收站、可撤销。

## 界面要求（按 PRD.md 主流程实现）

主窗口 `MainWindow` 包含：

1. **选目录**：目录选择按钮/输入框，默认「桌面/下载/文档」，也可自选任意文件夹。
2. **扫描按钮**：点击后调用 `scan_directory`，并用 `classify` 打好分类。
3. **清单表格**：展示每个文件 —— 文件名 / 大小 / 分类 / 建议目标路径，前面带勾选框（默认全选）。
4. **执行按钮**：对勾选的文件调用 `execute`，弹确认提示（"确认整理 N 个文件？"），确认后才执行。
5. **撤销按钮**：调用 `undo`。
6. **日志/统计区**：显示执行结果统计（移动了几个、进了回收站几个）和操作日志。

界面用 PySide6，简洁即可，不追求花哨。
